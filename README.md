# CardTune

**Fluency at Your Fingertips.**

CardTune is a classroom-focused flashcard application designed to help teachers create and present learning materials for small-group and whole-class instruction. Tuned to your needs. 

As an educator transitioning into software development, I wanted to build a practical tool inspired by classroom needs. CardTune allows teachers to create flashcards using letters, sounds, words, phrases, or images and organize them into separate decks for different instructional groups.

## Features

- **Create flashcards:** Enter or paste learning items, one per line.
- **Organize decks:** Save up to five independent decks for classroom practice.
- **Present and practice:** Display one flashcard at a time with simple Previous and Next controls.
- **Persistent storage:** Save decks in the browser using local storage.
- **Responsive design:** Designed with a clean interface and touch-friendly presentation controls.

## Getting Started

- Node.js and npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd your-project-folder
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## How It Works

Teachers enter letters, sounds, words, or phrases into the deck creator. CardTune saves the items as a deck that can be opened in presentation mode. Each saved deck can contain different content to support varied classroom learning needs.

Decks are stored locally in the browser. They do not automatically sync between devices or browsers.
